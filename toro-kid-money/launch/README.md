# TŌRO · Kid Money — launch assets

Filming pack and accreditation pack, prepared 12 May 2026.

## Contents

- **`launch-bundle-2026-05-12.pdf`** — twelve short-form video scripts (Kid-led × 4, Parent-led × 4, Receipt-led × 4) plus the four-week distribution plan that runs them through the Larry Loop (`dispatch-loop` skill). Designed to be shot back-to-back over one weekend with one kid and one parent on camera.

- **`three-agents-spec-2026-05-12.pdf`** — full build spec for the three TŌRO agents (Kid Money, Term Planner, Holiday Ideas) including phase-by-phase MVP scope, NZ-specific knowledge layer requirements, and the launch video concept.

## How to use the scripts

| Phase | What to do |
|---|---|
| **Week 0 — film** | Block one weekend. Same kid, same parent across all twelve scripts. Vertical 9:16, iPhone-grade is fine, natural light. No music in first 3 seconds. On-screen text in first 1 second. |
| **Week 1 — soft post** | Scripts 1, 5, and 9 (one kid-led, one parent-led, one receipt-led). No paid amp. Watch which one outperforms by 2×. |
| **Week 2 — double down** | Post two more in the winning hook style. One control from the other categories. |
| **Week 3 — Larry Loop** | Plug analytics into `dispatch-loop` skill. Larry generates three new scripts in winning style. Shoot one weekend, post one a day. |
| **Week 4 — paid amp on the breakout** | $200 of TikTok Spark Ads on the highest organic completion rate. NZ parents 30–50. Not a cent more. |
| **Months 2–3** | Scale (if >500k views breakout) or pivot (if nothing has cleared 100k). |

**Budget for the full launch: $0–$200 in paid amplification (week 4 only)** + one weekend of filming. Anything beyond that and we're forcing it.

## Note on production

The scripts assume the agent is in soft launch with the first 20 households before posting. We need the chore-and-photo loop working manually first (Phase 1 / Pre-CDR / weeks 1–6) so the footage is real — not staged. A staged demo will read as an ad and tank the organic reach.
